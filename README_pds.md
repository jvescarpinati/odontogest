# 🦷 OdontoGest

> Sistema de gerenciamento para consultórios odontológicos.

Trabalho Final da disciplina **Processo de Desenvolvimento de Software** — Bacharelado em Sistemas de Informação.

---

## 📌 Sobre o projeto

O OdontoGest permite que dentistas e recepcionistas gerenciem o dia a dia do consultório: cadastro de pacientes, agenda de consultas, prontuário/histórico de procedimentos e registro de cobranças.

## ✨ Funcionalidades

- [ ] Cadastro e busca de pacientes
- [ ] Agendamento, remarcação e cancelamento de consultas
- [ ] Prontuário e histórico de procedimentos
- [ ] Cadastro de procedimentos e valores
- [ ] Registro de cobranças (pago/pendente)
- [ ] Autenticação e perfis (dentista / recepção)

## 🛠️ Tecnologias

| Frontend | React |
| Backend  | Java |
